🔄 Technical Architecture & Data Workflow

📹
1. Video Input
Webcam / Mobile Camera frame capture via HTML5 MediaStream
🖐️
2. Landmark Tracking
Google MediaPipe Hands extracts 21 3D joint landmark coordinates
🧠
3. AI Classifier
Geometric angles & finger state heuristic + ML model match
🗣️
4. Speech / Text
Web Speech API synthesizes voice in English, Hindi, or Tamil
🚨
5. Emergency Dispatch
GPS Geolocation pin dispatched to WhatsApp, SMS & Siren
